# BrainDump

**A simple, focused space to capture thoughts, organize ideas, and manage tasks.**

BrainDump is a lightweight, browser-based productivity dashboard designed to help you get thoughts out of your head and keep everything organized in one place.

## Features

* **Quick Capture** — Record thoughts without interrupting your workflow.
* **Categories** — Organize ideas, tasks, notes, projects, and personal thoughts.
* **Pinned Thoughts** — Keep important items within easy reach.
* **Task Management** — Track tasks and mark them as completed.
* **Search and Sorting** — Find specific thoughts and organize your dashboard.
* **Drag and Drop** — Rearrange thoughts to suit your workflow.
* **Local Storage** — Keep your data saved in your browser.
* **Data Export** — Export your thoughts as a JSON backup.
* **Keyboard Shortcuts** — Navigate and create thoughts more efficiently.
* **Responsive Interface** — Designed for different screen sizes.
* **Dark Theme** — A minimal interface with blue accents.

## Getting Started

### Use BrainDump Online

Visit the live website:

[Open BrainDump](https://burittobean.github.io/BrainDump/)

If the website is unavailable, check that GitHub Pages is enabled in the repository settings.

### Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Start organizing your thoughts.

BrainDump requires no installation, build tools, or external dependencies.

## Technology Stack

* HTML
* CSS
* JavaScript
* Browser Local Storage

## Privacy and Data Storage

BrainDump stores data locally in your browser. Your thoughts are not automatically synchronized across devices or backed up to a cloud database.

Clearing browser data or switching browsers or devices may make your saved thoughts unavailable. Export backups regularly to help protect your data.
